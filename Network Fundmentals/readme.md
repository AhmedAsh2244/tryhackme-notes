# Network Fundamentals Module | TryHackMe

## Overview
This module establishes core networking concepts essential for cybersecurity, covering how data moves across networks and the frameworks that govern communication.

### Topics Covered:
- **What is Networking?**: Fundamentals of computer networking
- **Intro to LAN**: Technologies and designs powering private networks
- **OSI Model**: The 7-layer framework for network communication
- **Packets & Frames**: How data is divided and transmitted across networks
- **Extending Your Network**: Technologies connecting networks to the Internet

### Skills Gained:
- Understanding of LAN/WAN concepts and topologies
- OSI model layers and data encapsulation
- Packet analysis fundamentals
- Network devices and protocols overview
- Foundation for Network Exploitation and Defense
