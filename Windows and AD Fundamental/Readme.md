
# Windows and AD Fundamentals Module | TryHackMe

## Overview
This module provides hands-on experience with Windows OS and Active Directory, focusing on security controls needed for identifying, exploiting, and defending Windows environments.

### Topics Covered:
- **Windows Fundamentals 1**: Desktop, NTFS file system, UAC, Control Panel
- **Windows Fundamentals 2**: System Configuration, Resource Monitoring, Windows Registry
- **Windows Fundamentals 3**: Windows Updates, Windows Security, BitLocker
- **Active Directory Basics**: Core AD concepts and functionality

### Skills Gained:
- Windows system administration and security hardening
- User account permissions and UAC management
- Registry analysis and resource monitoring
- Active Directory fundamentals for enterprise environments
- Foundation for Windows exploitation and defense
